# Study Materials

## Overview

This repository contains the assignment materials used in a study on the usability of Git commit signing.

---

## Repository Contents

- `Part1.md` — Assignment instructions for Part 1: initial setup of cryptographic keys and Git commit signing, including the ASQ and SUS survey instruments administered to participants.
- `Part2.md` — Assignment instructions for Part 2: cross-device key synchronization, commit history analysis, semester-long reflection, and thought exercises, including the ASQ and SUS survey instruments administered to participants.
- `analysis.py` — The complete analysis script used to process participant Git repositories, verify commit signatures, compute ASQ and SUS scores, and conduct all statistical tests reported in the paper.
- `consent_form.md` — The redacted consent form presented to participants prior to data
  analysis, describing the study purpose, data handling procedures, and participant rights.
- `recruitment_email.md` — The redacted recruitment email sent to students after the semester concluded, soliciting consent to use their course submissions for research purposes.
