# Study Materials: A Multi-Month Study of Git Commit Signing

## Overview

This repository contains the assignment materials, survey instruments, qualitative codebook, and analysis scripts used in the study *"A Multi-Month Study of Git Commit Signing"*.

---

## Repository Contents

- `Part1.md` — Assignment instructions for Part 1: initial setup of cryptographic keys and Git commit signing, including the ASQ and SUS survey instruments administered to participants.
- `Part2.md` — Assignment instructions for Part 2: cross-device key synchronization, commit history verification, semester-long reflection, and security-reasoning prompts, including the post-task ASQ and end-of-semester SUS instruments.
- `analysis.py` — The complete analysis script used to process participant Git repositories, verify commit signatures, compute ASQ and SUS scores, and conduct all statistical tests reported in the paper.
- `codebook_git_study.pdf` — The qualitative analysis codebook and coding schema applied to participants' written self-reports and security-reasoning responses.
- `consent_form.md` — The redacted consent form presented to participants prior to data analysis, outlining the study purpose, data handling procedures, and participant rights.
- `recruitment_email.md` — The redacted recruitment email sent to students after the semester concluded, soliciting opt-in consent to analyze their course submissions for research purposes.
